AgroSense REST API

Backend API for the AgroSense agricultural monitoring platform. Manage estates, crops, sensors, irrigation cycles, alerts and AI-powered irrigation predictions.

Base URL  /api Auth  JWT Bearer (after login) Roles  ADMIN · FARMER · TECHNICIAN Format  JSON

Authorization

Most endpoints require authentication. Role checks are applied in addition to ownership: every operation is limited to the authenticated user's own estates.

RolePermissions
ADMIN / FARMER Full access (Manager): create estates & crops, irrigate, acknowledge alerts, request predictions
TECHNICIAN Read data, record sensor readings, register sensors
Public Health check and login only

POST /api/crops/{cropId}/predictions MANAGER ▾

Description

Starts an irrigation prediction using the crop's latest sensor readings. Ownership is verified on the request thread (foreign crops return 404). The response is empty; poll the history endpoint for the result.
